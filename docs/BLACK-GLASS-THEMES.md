# Code Black glass and Cozy

Code Black uses deep black foundations, charcoal glass surfaces, thin white borders, white headings and neutral supporting text. Shared design tokens and the final black-glass skin cover navigation, media cards, menus, dialogs, creator/upload controls, install/display controls and sticky players. Hero photography, footage, content and route layouts are preserved. Watch now and Explore music share the same glass treatment; the white Divine mark and Connection headline have no warm tint.

The prior Default theme is labelled **Cozy** and intentionally retains Divine brand yellow for its primary actions, active navigation, labels and progress controls. Its existing `default` preference ID stays compatible with stored preferences, cookies and links. `?theme=cozy` is accepted as an alias. Yellow interface rules exist only under the Cozy root selectors; they do not apply to Code Black.

A shared icon adapter decorates the existing Lucide action icons with consistent glass badges, cool cyan/blue/purple/pink/green gradients and small local highlights. SVG gradients use user-space coordinates so straight icon strokes remain visible. Dismiss/back glyphs stay neutral. No new runtime dependency or reference artwork import is required. Brand icons now share a flat cool-gradient Divine mark with a faint transparent backlight. Standard PWA icons are transparent; the separate maskable and Apple variants have an opaque black base. Wordmark text stays white. Cozy’s yellow action buttons use solid black play glyphs. The offline-worker cache version is advanced for refreshed public icon assets; private data/media caching behavior is unchanged.

Solid charcoal surface declarations are the default where backdrop blur is unsupported. A simulated unsupported feature-query render verified that fallback. Focus outlines are explicit and high contrast; reduced-motion mode suppresses CSS animation/transitions and preserves readable revealed content. Browser screenshots/checks cover both themes at 1440/390/320px, the homepage, navigation, cards, video/player menus, sticky player, and upload controls. Full existing isolated frontend interactions, 30 unit tests and production build pass. No live accounts were used or backend data changed.

The source palette audit found no remaining warm interface values outside the intentionally scoped Cozy yellow rules. No source artwork, JPEG imagery or audio/video files were changed. See BLACK-GLASS-PALETTE-AUDIT.json and BLACK-GLASS-BROWSER-VERIFICATION.json.

This work is prepared on a feature branch for a Netlify review preview; it has not been published to production. The separate user-specific login rejection and real-receiver Cast/AirPlay validation remain outside this theme change.
